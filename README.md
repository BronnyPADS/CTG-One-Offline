# CTG One - offline version

A practice copy of CTG One that runs entirely in your browser (Google Chrome or
Microsoft Edge). Nothing you enter is sent anywhere.

## Open it online

**https://bronnypads.github.io/CTG-One-Offline/**

Just open the link (bookmark it). It is always the latest version.

## Or download it (works without internet)

1. On this page, click the green **Code** button, then **Download ZIP**.
2. Right-click the downloaded ZIP and choose **Extract All**.
3. Open the extracted folder and double-click **index.html**. If it opens in
   another program, right-click it, choose **Open with**, and pick Chrome or Edge.

When CTG One is updated, download the ZIP again the same way.

Your saved work stays in the browser, not in the folder, so a newly downloaded
version opens with it - as long as you use the same browser on the same
computer. You can delete the old folder.

The website and a downloaded copy keep separate saved work, even in the same
browser.

## Using it

Work as normal: register a patient, fill in Day 1, exams, daily notes and
billing, then download the FCR from the patient's Final Case Report.

No form to fill? Use **Upload Day 1 File** (Patients Pending for Day 1, or a
patient's Day 1 tab) and **Upload Billing File** (the Billing tab). While a
billing file is attached, automatic billing from Day 1, Day 2 and notes is
paused for that patient; remove the file to turn it back on.

Everything is saved in your browser on your own computer only. Uploaded
documents use the computer's free space (up to 150 MB a file and 1 GB a
patient). Clearing the browser's site data removes it all, and nothing copies
to other computers.

**Use made-up test patients only, never real patient information:** this
offline copy is not protected like the real CTG One.

Not available offline: video meetings, messaging, texts/emails to patients,
emailed sign-in codes, RecoverArc notes, backups.
